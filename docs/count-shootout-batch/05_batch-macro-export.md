# Batch macro export

## Why this stage exists

Users want the macro they just validated to be reusable on a batch, not trapped inside the interactive test session. This stage adds a save option that exports a batch-applicable macro and warns when the current macro is likely to be unsafe for batch use.

- `01_count-model-native-counter.md` completed and renamed with `_COMPLETED`.
- `02_threshold-shootout-runner.md` completed and renamed with `_COMPLETED`.
- `04_batch-shootout-runner.md` completed and renamed with `_COMPLETED`.

## Scope

- Add `Save batch macro...` near `Save macro...`.
- Add a batch-compatibility checker for common unsafe macro patterns.
- Save a wrapper `.ijm` that can run the current macro across a folder.
- For count testing, save settings next to the macro and make the macro call a Macro Builder batch plugin command so native 3D counting remains available.
- Register a macro-callable batch command if needed.

## Out of scope

- Publishing to GitHub Actions or Fiji update sites.
- Replacing the existing plain `Save macro...`.
- Building a lab-specific import workflow.

## Implementation sketch

Unsafe pattern warnings should be conservative:

```text
selectWindow("...") with a fixed non-temporary title
waitForUser
open("...") or File.open("...")
saveAs("...", "...") with a hard-coded path
close("*") or Close All
```

Wrapper macro outline:

```ijm
// Generated by Macro Builder.
input = getDirectory("Choose input folder");
output = getDirectory("Choose output folder");
run("Macro Builder Batch Count", "settings=[...settings.json] input=[" + input + "] output=[" + output + "]");
```

The sidecar settings should include:

```json
{
  "macroPath": "Macro_Builder_Filter.ijm",
  "countingMode": "OBJECTS_3D",
  "thresholdMode": "AUTO_AND_FIXED",
  "autoMethods": ["Otsu", "Li"],
  "fixedThresholds": [2000.0],
  "minSize": 100.0,
  "maxSize": "Infinity"
}
```

If implementing the plugin command is too large, export the processing-only batch macro first and clearly disable count-export for 3D until the command is available.

## Exit gate

1. `.\mvnw.cmd test "-Denforcer.skip=true"` passes.
2. Manual: `Save macro...` still writes the original plain `.ijm`.
3. Manual: `Save batch macro...` writes a wrapper macro plus sidecar settings.
4. Manual: a macro containing `waitForUser` produces a visible compatibility warning before export.
5. Manual: exported batch count macro can run from Fiji's macro runner on a small image folder.

## Known risks

- Pure ImageJ macro code cannot reproduce the native Java 3D counter by itself. Use a Macro Builder plugin command for batch count execution, or clearly warn when exporting a processing-only macro.
- Settings JSON must stay compatible with future versions. Prefer explicit field names and defaults over positional data.
